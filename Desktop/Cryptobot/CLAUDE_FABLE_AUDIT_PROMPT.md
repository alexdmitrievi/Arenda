> Вставь этот промпт целиком в Claude Fable для всестороннего аудита проекта.

```
Ты — Senior Engineering Lead с опытом в crypto fintech (20+ лет), архитектор
высоконагруженных торговых систем, ex-quant в хедж-фонде, product-стратег с
опытом вывода B2C SaaS на рынок. Твоя задача — провести всесторонний аудит
проекта «TBX Trade Terminal» и дать конкретные, реализуемые рекомендации.

## КОНТЕКСТ

Мы строим regime-aware intraday trading system на базе Smart Money Concepts для
крипторынка. Цель: продукт, который друзья/клиенты открывают → видят SMC-сигналы
→ подтверждают → бот исполняет на Bybit.

Стек: Python FastAPI + PostgreSQL + Redis + Next.js/PWA + Telegram Bot + Docker.
Монетизация: Start (бесплатно по рефералке Bybit), Trader ($29/мес), Pro ($79/мес).

## ЧТО УЖЕ ПОСТРОЕНО (СЖАТЫЙ АУДИТ)

### Безусловные плюсы:
- SMC-движок на 486 строк: rule-based (без AI), чистый math — swing points, BOS,
  CHOCH, FVG, Order Blocks, Fibonacci, confidence scoring. Работает детерминированно.
- CCXT-интеграция с Binance/Bybit/OKX: полный жизненный цикл ордера.
- Risk-менеджер: DailyLossTracker, DrawdownTracker, position sizing.
- Модели БД: User, Trade, Position, Signal, Strategy, Subscription, Payment,
  Invoice, Portfolio, DCAPlan, PropFirmChallenge — полная ORM-модель.
- FastAPI с JWT-авторизацией, ролями, subscription guard.
- CryptoCloud webhook (USDT-платежи) + YooKassa (RUB-платежи).
- Веб-дашборд (Next.js): сигналы, исполнение, позиции, история трейдов.
- PWA: манифест, service worker, установка на телефон.
- Docker Compose: PostgreSQL 16, Redis 7, backend.
- Telegram бот: /signals, /signal команды; DeepSeek Vision для AI-анализа чартов.
- Тесты: 14 unit-тестов для SMC-движка (swing points, BOS, FVG, Fib, signals).

### Критические проблемы (должны быть в топе рекомендаций):

1. ENCRYPTION_KEY пустой в .env → Fernet генерирует случайный ключ при каждом
   рестарте → ВСЕ зашифрованные API-ключи бирж становятся нечитаемыми.
   Данные не теряются, но расшифровать невозможно. Это блокер для продакшена.

2. SMC-движок: _find_targets всегда возвращает цели ВЫШЕ входа — даже для SELL.
   Шортовые тейк-профиты указывают цены дороже входа. Логическая ошибка в коде.

3. Два независимых Telegram-бота в проекте:
   - root/bot.py (2982 строки): GPT-4o Vision + Google Sheets. Реально работает.
   - backend/app/bot/ (модульный): DeepSeek + PostgreSQL. Частично реализован.
   Они не делят код, не синхронизируют состояние. Дублируют SMC-промпты,
   модели подписок несовместимы.

4. Celery-воркеры объявлены, но НЕ запускаются нигде: не в Docker Compose,
   не в lifespan. Фактически мёртвый код.

5. Исполнение на Bybit: если ордер на бирже проходит, а запись в БД — нет,
   позиция существует без Trade-записи в системе. Нет транзакционной атомарности.

6. CryptoCloud webhook: при ошибке парсинга amount (Decimal(str(None)))
   необработанное исключение роняет webhook. Платёж принят, подписка не выдана.

7. /users/me PATCH эндпоинт: изменения username/email не сохраняются в БД
   (нет await db.commit() после присвоения). Data loss bug.

8. Risk-менеджер (risk.py) НЕ используется в реальном исполнении — signals.py
   дублирует логику position sizing инлайн. Два источника истины.

9. Коллектор данных открывает ДВА WebSocket-соединения к Binance: одно для
   тикеров (никогда не используется для сигналов), второе для OHLCV.
   Избыточное потребление ресурсов.

10. Коллектор на каждую закрытую свечу делает REST-запрос fetch_ohlcv(500)
    вместо использования уже полученных данных из WebSocket.
    Лишняя нагрузка на API Binance, риск rate-limit.

### Средние проблемы:
- SMC-движок хардкодит timeframe="4h", но коллектор шлёт 1h данные.
  Несоответствие таймфреймов.
- Order Block detection — примитивный (только 3-свечной паттерн).
  Liquidity detection — только equal highs/lows, не sweep-события.
- Нет комиссий и funding rate в backtest и execution.
- Нет индексов на (symbol, created_at) в таблице signals — будет тормозить.
- exchange.py: EXCHANGE_MAP ссылается на ccxt_async даже если ccxt не установлен.
- Фронтенд: нет real-time обновлений (polling каждые 30 сек), нет графиков цен,
  нет PnL-агрегации, нет уведомлений.
- frontend/src/lib/api.ts: токен в localStorage (XSS-уязвимость), нет refresh-логики.
- Два разных Base(DeclarativeBase) в проекте: один в core/database.py,
  другой в models/base.py. Потенциальный конфликт метаданных.

### Что отсутствует полностью:
- Нет backtest/replay системы для валидации стратегии перед реальными деньгами
- Нет real-time уведомлений о сигналах через WebSocket/SSE
- Нет графиков/чартов на фронтенде
- Нет email-верификации (заглушка _send_verification_email ничего не делает)
- Нет rate-limiting на /login и /register (уязвимость к брутфорсу)
- Нет journal/diary для трейдера (почему вошёл, почему вышел)
- Нет multi-timeframe анализа в SMC-движке
- Нет поддержки нескольких бирж в execution (только Bybit)
- Нет мониторинга состояния системы (health checks для collector, exchange)
- Нет алертов (Telegram push на сигналы — заглушка)

### Тарифы и монетизация (статус):
- Модель: Start (бесплатно по рефералке Bybit) → Trader ($29/мес) → Pro ($79/мес)
- SubscriptionPlan enum: demo/trader/investor_pro/prop_firm_master/enterprise
- PLAN_PRICES: 0/29/79/149/0 (USD)
- CryptoCloud (USDT) + YooKassa (RUB) — два платёжных провайдера
- Root bot.py использует другие цены: MONTHLY_PRICE_USD=25, LIFETIME_PRICE_USD=199
  → конфликт цен между ботами
- Бесплатный доступ: guard проверяет user.referred_by (рефералка) ИЛИ активную
  подписку ИЛИ trial. Но установка referred_by никак не верифицируется —
  любой пользователь может просто указать реферала и получить бесплатный доступ.
- Нет триального периода при регистрации (trial активируется вручную)
- Нет годовых тарифов со скидкой
- Нет affiliate/referral программы для пользователей
- Нет автоматического напоминания об истечении подписки

### Реферальная программа:
- Root bot.py: broker referral — пользователь отправляет UID (Bybit/Forex4You),
  сохраняется в Google Sheets, получает бесплатный доступ
- Backend: User.referred_by — просто строка, не проверяется
- Отсутствует: трекинг кто кого пригласил, процент с реферала, dashboard
  для рефереров, автоматическая привязка Bybit UID к аккаунту
```

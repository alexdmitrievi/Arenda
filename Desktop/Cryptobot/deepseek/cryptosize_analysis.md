# Анализ канала @CryptoSizeRU — 50 последних постов (май–июль 2026)

Выгружено 20.08.2026 через t.me web-preview (50 сообщений, 60 скриншотов терминала
TigerTrade, OCR через Windows OCR). Источник: `backend/scripts/channel_web.py`.

## Фактура постов

- Публикуются: пары с зонами/идеями, редкие «железки» (лучшие сетапы), ход сделок,
  заметки про проп-челленджи (TigerTrade), иногда сигналы по фьючерсам металлов (мамба).
- Явная философия автора (пост 448): «мало сетапов, но качественные», без воды.
- Посты часто = скриншот графика + короткий текст: пара, направление, «жду зону»,
  «пробой», «реакция», «цели», «изи стоп».

## Стиль торговли (что извлечено из текстов и OCR скриншотов)

1. **Инструмент**: бессрочные фьючерсы альткоинов (HYPE, ZEC, LAB, JTO, STORJ, TLM,
   RE, HEI, SIREN, PORTAL, MU, ID, BSB, SPCX, ETH) — и LONG, и SHORT.
2. **Таймфреймы**: на скринах видны **1ч** (зона Н1, «пробую от зоны Н1»), **4ч**,
   встречается 15м как триггер. Явной 15м-торговли нет — входы от зон на Н1/Н4.
3. **Формации**: зоны по объёму/плотности заявок («плотка», «стакан нигде не держит»),
   **ордер-блоки (ОБ)** («ОБ себя отработала», «плотка защищает ОБ»), реакции от зон,
   пробои («пробой плотки»), импульсы, цели «до последних».
4. **Селективность**: сетапов мало — рынок даёт их редко, «железка» = А+-качество.
5. **Риск**: стоп ставится «изи» (короткий, структурный), несколько целей по ходу.

## Сопоставление с нашим SMC-движком

| Компонент канала | У нас | Статус |
|---|---|---|
| Ордер-блоки (ОБ) | detect_order_blocks + displacement-фильтр | ✓ совпадает |
| Зоны/ликвидность | equal highs/lows + sweeps | ✓ совпадает |
| Входы от зоны Н1 | движок на 1h, вход в OTE-зону ретрейса | ✓ совпадает |
| Контекст старшего ТФ | 4h bias (BOS) | ✓ совпадает |
| Редкие качественные сетапы | confidence ≥ 50 + RR ≥ 3 + CHOP veto + BTC gate | ✓ совпадает по духу |
| LONG и SHORT | генерируются оба; исполнение шортов — после включения | частично |
| Объём/плотность (стакан) | НЕТ (у нас только OHLCV) | ✗ нет аналога |
| Зоны по объёму (Volume Profile POC/VA) | НЕТ | ✗ нет |
| Цели «до последних» | TP 3R/5R/7R | ✓ похоже |

## Предлагаемые правки (на утверждение владельцу)

1. **Пары под канал**: заменить часть нашего списка парами автора
   (ZEC, LAB, JTO, STORJ, TLM, HYPE, RE, HEI...) — сверить листинг Bybit perps.
2. **Volume Profile**: добавить фактор POC/VAH/VAL (по историческим барам) —
   «цена в зоне объёма» +5..+10 к confidence. Стакан в реальном времени недоступен
   бесплатно — не берём.
3. **Лимит зоны стопа**: сигналы со стопом шире N% (предлагаю 10%) — помечать/фильтровать
   (стыкуется с калькулятором риска: стоп 7% → объём позиции адекватный).
4. **Шорты**: включить исполнение SELL на фьючерсах (владелец ранее: BUY-only пока).
5. **Порог confidence**: оставить 50 (или поднять до 55–60 для «режима железок») —
   решение владельца.
